## Description

This repository contains the data and R scripts for the analysis presented in:

> **Singh, R.**, Hager, A., Lancaster, S., Norsworthy, J.K., Gage, K., Johnson, W., Young, B., Stephenson, D., Bond, J., Bradley, K., Jhala, A., Essman, A., Steckel, L.E., Mueller, T.C., Sprague, C., Legleiter, T., Werle, R., Ikley, J., Jha, P., & Jugulam, M. (2025). Optimizing metribuzin rates for herbicide-resistant *Amaranthus* weed control in soybean. *Weed Technology*, 39, e97. https://doi.org/10.1017/wet.2025.10047

### Background

Palmer amaranth (*Amaranthus palmeri* S. Watson) and waterhemp (*Amaranthus tuberculatus* (Moq.) Sauer) are among the most troublesome weeds in U.S. soybean production systems. The rapid evolution of resistance to herbicides from multiple sites of action in these species warrants alternative weed control options. Metribuzin, a photosystem II inhibitor applied preemergence, can provide effective residual control of herbicide-resistant *Amaranthus* species.

### Study Objectives

1. Determine the optimal metribuzin dose for residual control of herbicide-resistant Palmer amaranth and waterhemp under varied soil and environmental conditions
2. Evaluate early season soybean growth and development following preemergence application of metribuzin at multiple doses
3. Determine whether potential early season herbicide-induced injury affects soybean yield

### Experimental Design

- **Locations**: 15 U.S. states (27 site-years across 2022-2023)
- **Design**: Randomized complete block design with 3-4 replications
- **Treatments**: 17 preemergence treatments including:
  - 13 metribuzin doses (210 to 841 g ai ha⁻¹)
  - Sulfentrazone (420 g ai ha⁻¹)
  - S-metolachlor (1,790 g ai ha⁻¹)
  - Non-treated and weed-free controls

### Key Findings

- **Weed Control**: Metribuzin doses of 578-841 g ai ha⁻¹ provided >95%, >90%, and >80% weed control at 14, 28, and 42 DAA, respectively
- **Crop Safety**: Soybean injury remained ≤5% even at the highest dose (841 g ai ha⁻¹)
- **Yield**: No significant yield reduction across metribuzin treatments
- **Comparison**: Metribuzin at 630 g ai ha⁻¹ outperformed sulfentrazone; 315 g ai ha⁻¹ outperformed S-metolachlor

## Statistical Methods

| Analysis | Method | R Package | Output |
|----------|--------|-----------|--------|
| Site-year characterization | Principal Component Analysis | `stats::prcomp` | Fig 2 |
| Weed control dose-response | Generalized Additive Model | `mgcv::gam` | Fig 3-4, Table 5-6 |
| Weed parameters dose-response | GAM + LMER | `mgcv`, `lme4` | Fig 5-7 |
| Treatment comparisons | Tukey HSD | `emmeans`, `multcomp` | Fig 8-9 |

## Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/[username]/metribuzin-amaranthus-control.git
   cd metribuzin-amaranthus-control
   ```

2. **Open the R project in RStudio** (or set working directory)

3. **Run scripts in order**
   ```r
   source("scripts/01_PCA_Analysis.R")
   source("scripts/02_Weed_Control_Crop_Injury_GAM.R")
   source("scripts/03_Weed_Parameters_Analysis.R")
   source("scripts/04_Soybean_Parameters_Analysis.R")
   ```

4. **Outputs** will be saved to `figures/` and `output/` directories

## Variables Description

### Environmental Variables (PCA.xlsx)
| Variable | Description | Unit |
|----------|-------------|------|
| Soil OM | Soil organic matter | % |
| Soil pH | Soil pH | - |
| Clay, Silt, Sand | Soil texture | % |
| Soil temperature | Temperature at application | °F |
| Soil moisture | Moisture at application | Categorical |
| Interval of 1st precipitation | Days to first rainfall | days |
| Cumulative Precipitation 42 DAA | Total rainfall through 42 DAA | inches |

### Response Variables
| Variable | Description | Unit |
|----------|-------------|------|
| control | Weed control rating | % of non-treated |
| density | Weed density at 28 DAA | plants m⁻² |
| biomass | Dry aboveground biomass at 28 DAA | g m⁻² |
| emergence | Days to first weed emergence | DAA |
| ci.14dat, ci.28dat, ci.42dat | Crop injury | % |
| soy.ht.cm | Soybean height | cm |
| soy.yield.bu/a | Soybean yield | bu A⁻¹ |
